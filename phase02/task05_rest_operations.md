
# Task 05 — Build a REST API Operation Table

## REST API Operations

| Operation | HTTP Method | Endpoint |
|---|---|---|
| Retrieve all students | GET | /students |
| Create a student | POST | /students |
| Retrieve student 101 | GET | /students/101 |
| Update student 101 | PUT | /students/101 |
| Delete student 101 | DELETE | /students/101 |

## Why Are Different HTTP Methods Used?

Different HTTP methods are used because each method represents a different operation on a resource.

GET is used to retrieve existing data.
POST is used to create a new resource.
PUT is used to update an existing resource.
DELETE is used to remove a resource.

Using the appropriate HTTP method makes API operations clear and follows REST API conventions.
