
# Task 09 — DELETE Operation

## Purpose

The DELETE operation is used to request the removal of a specific resource from a server.

In this task, a DELETE request is sent to `/posts/1` to request deletion of post ID 1.

## Result

The HTTP status code and response are checked to determine the result of the request.

JSONPlaceholder is a testing API, so the successful response simulates deletion and does not permanently modify a real database.
