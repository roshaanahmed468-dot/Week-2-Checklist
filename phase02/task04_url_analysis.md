
# Task 04 — Analyze a URL

## Given URL

https://api.example.com/students/101

## URL Analysis Table

| Component | Value | Explanation |
|---|---|---|
| Protocol | HTTPS | Defines the communication protocol. |
| Host | api.example.com | Identifies the API host. |
| Path | /students/101 | Specifies the requested resource path. |
| Resource | students | Identifies the type of resource. |
| Resource Identifier | 101 | Identifies the specific student. |

## Conclusion

The URL uses HTTPS to communicate with the API host.
The path `/students/101` identifies the students resource
and specifies student 101 as the requested resource.
